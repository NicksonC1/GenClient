## Asymptotic PID simulator

Open [`pid-simulator.html`](pid-simulator.html) in a desktop browser. It is self-contained and does not require npm or affect the PROS firmware build.

The simulator provides angle presets from 10° to 180°, the exact library gain and PID calculations, an adjustable robot-response model, exit-condition indicators, live graphs, and a copyable C++ controller profile.
